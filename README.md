Xbox Game Pass | Performance Executive Dashboard

Este projeto foi desenvolvido como parte de um desafio da DIO (Digital Innovation One), com o objetivo de criar um dashboard executivo interativo utilizando o Microsoft Excel para analisar o desempenho do serviço Xbox Game Pass.

----> O Projeto
O dashboard apresenta KPIs (Key Performance Indicators) essenciais para a tomada de decisão estratégica, permitindo visualizar a saúde financeira e a base de clientes de forma dinâmica.

----> Principais Indicadores (KPIs):
Receita Total: Valor bruto acumulado;
Total de Assinantes: Volume de usuários ativos na base;
Ticket Médio Global: Valor médio gasto por usuário;
Taxa de Renovação: Porcentagem de clientes que mantêm a assinatura ativa.

----> Tecnologias e Ferramentas Utilizadas
Microsoft Excel: Processamento de dados e design do dashboard;
Tabelas Dinâmicas: Para sumarização rápida de grandes volumes de dados;
Segmentadores (Slicers): Filtros interativos por Tipo de Assinatura e Renovação Automática;
Células de Apoio: Técnica avançada para vincular formas (shapes) a dados dinâmicos, evitando erros de referência;

----> Como Visualizar
Faça o download do arquivo .xlsx presente neste repositório;

----> Utilize os filtros laterais para interagir com os gráficos e cards em tempo real.
